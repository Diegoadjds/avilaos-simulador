ÁvilaOS Simulador

Simulador de un sistema operativo con un computador y un disco: planificación de procesos de CPU y de archivos, sistema de archivos jerárquico sobre un disco de bloques, planificación de disco (FIFO, SSTF, SCAN, C-SCAN, LOOK y C-LOOK) y suspensión de procesos al área de intercambio (swap).

Proyecto 2 de Sistemas Operativos, Universidad Metropolitana (trimestre 2627-1).

Integrantes: Diego De Jesús (@Diegoadjds) Sofía Machado (@sofia-machado1910)

Requisitos:
Java (JDK 25)
Apache NetBeans 31
Maven
